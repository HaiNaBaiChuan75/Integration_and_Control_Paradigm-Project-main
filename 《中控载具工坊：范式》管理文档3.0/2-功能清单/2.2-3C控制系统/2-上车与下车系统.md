# 2. 上车/下车系统

## 上车方式

**唯一途径：空手右键驾驶舱方块。**

适用方块：
- `BaseCabinBlock`（基础座舱，1 格，GeckoLib 骨骼动画）

不再支持的旧途径（已移除）：
- ❌ F 键射线检测上车
- ❌ CockpitUpperBlock 右键上车
- ❌ 结构完整性检查（上下格配对）
- ❌ 独占性检查（同一 SubLevel 只能一人）

## 上车流程

```
玩家右键 BaseCabinBlock
  ├→ 检测 Shift 按下 → PASS（不处理）
  ├→ 客户端 → SUCCESS（服务端处理）
  └→ 服务端：
       ├→ 已有 IACPSeatEntity → 弹出当前乘客 → 换人
       └→ 无座位 → IACPSeatEntity.sitDown(level, pos, player)
```

### IACPSeatEntity 生命周期

```
创建：sitDown() → new IACPSeatEntity(level, homePos) → level.addFreshEntity()
存活条件：有乘客 OR 下方方块仍是 BaseCabinBlock
销毁：方块消失且无乘客 → discard()
```

### 每 tick 行为

不同于旧系统的服务端位置同步，新系统通过原版骑乘机制：

```
双端执行 followSubLevelPose():
  1. subLevel.logicalPose().transformPosition(homePos) → 世界坐标
  2. setPos(worldX, worldY, worldZ) — 更新座位实体位置
  3. 从 pose 计算偏航 → setYRot(yaw) — 座位朝向跟随 SubLevel
  4. 帧间偏航变化量存储为 lastYawDelta

服务端（额外执行）:
  5. 将 yawDelta 应用到所有骑乘者 setYRot(yRot + delta)
  6. 生命周期检测（方块消失 → discard）

客户端（额外执行 — ClientMountGameHandler）:
  5. 读取座位 lastYawDelta → 应用到本地玩家 yRot
     → 使玩家身体跟随 SubLevel 水平旋转
```

> jitter 修复：客户端不再依赖服务端 20Hz 实体同步包，而是直接读取本地 SubLevel logicalPose() 更新座位位置。vanilla 实体插值自动平滑帧间过渡。
>
> 旋转修复：帧间偏航 delta 通过 `passenger.setYRot(yRot + delta)` 传递，服务端权威同步到所有客户端。本地玩家由 `ClientMountGameHandler.onClientTickPost` 在 EntityTick 后额外修正。

## 下车方式

**Shift 键下车（默认 LEFT_SHIFT，可在按键设置中修改）。**

- 由原版 `stopRiding()` 自动处理
- 下车位置：`getDismountLocationForPassenger()` → 座位当前位置 + Y+0.5
- 原版安全搜索：如果该位置不安全，自动搜索周围可用位置

## 骑乘交互阻断

### 客户端事件

| 事件 | 阻断内容 |
|------|---------|
| `MovementInputUpdateEvent` | WASD/跳跃/潜行对玩家实体的影响归零（按键仍发送到载具控制） |
| `RightClickBlock/Item` | 右键方块/物品 → canceled |
| `LeftClickBlock` | 左键方块 → canceled |
| `EntityInteract` | 实体交互 → canceled |
| `ScreenEvent.Opening` | 物品栏 (E) → canceled |
| `ClientTickEvent.Pre` | Q/E 按键点击计数消耗 |

### 服务端事件

| 事件 | 阻断内容 |
|------|---------|
| `PlayerTickEvent.Pre` | 每 tick 设置 `setDeltaMovement(Vec3.ZERO)` |

## 轨道摄像机
