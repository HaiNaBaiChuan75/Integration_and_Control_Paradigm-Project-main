# 2. 发动机模型

> ⚠ 06-27 重大简化：移除 RPM 扭矩曲线 / 连续油门 / 质量自适应扭矩 / 扭矩平衡负载模型 / 发动机-轮速耦合。
> 新模型：油门线性扭矩，扭矩与 RPM 完全解耦。

### 核心公式

```
RPM   = ENGINE_IDLE_RPM + throttle × (ENGINE_MAX_RPM - ENGINE_IDLE_RPM)
扭矩  = TORQUE_MIN + throttle × (TORQUE_MAX - TORQUE_MIN)
```

- **油门始终 100%**：`throttleLevel` 恒为 1.0，引擎永远工作在最大状态
- **扭矩与 RPM 解耦**：不再有 `torqueCurve(RPM)` 的 sin 曲线修正
- **WASD 仅控制 BinaryGrip 方向**，不控制油门深浅

### 基础参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `ENGINE_IDLE_RPM` | 800 | 0% 油门时转速（实际运行中由 throttle=1.0 覆盖） |
| `ENGINE_MAX_RPM` | 6,000 | 100% 油门时转速 |
| `TORQUE_MAX` | **5.0 Nm** (06-27 新增) | 100% 油门扭矩 |
| `TORQUE_MIN` | **4.0 Nm** (06-27 新增) | 0% 油门扭矩（起步平顺不窜动） |

### 默认全油门（06-27 新增）

```
throttleLevel = 1.0  // 恒为 1.0，无渐变
```

- 不再需要 `updateThrottle()` 渐变上升
- 引擎始终输出 `TORQUE_MAX = 5.0 Nm`
- RPM 始终 6,000（仅作为齿比计算目标和覆盖层显示）
- 松 W/S 时 BinaryGrip direction=0 → 轮端驱动力归零 → 车辆滑行

### 空档自动挂档（06-27 新增）

```
if (currentGear == 0 && rawThrottleDirection != 0) {
    currentGear = 1;  // W/S 按下时瞬跳 1 档
}
```

- 无换挡真空期，无延迟
- 适用于：上车后直接按 W 就走，无需先按 Q 挂档

### 变速箱输出

```
变速箱输出 = 引擎扭矩 × 齿比 × 主减速比 ÷ 轮数
```

例（4 轮，1 档）：5.0 × 4.0 × 14.0 ÷ 4 = 70 Nm/轮

### 已移除的功能

| 旧功能 | 移除原因 | 替代方案 |
|--------|---------|---------|
| 扭矩曲线（sin 曲线 RPM 修正） | 游戏性不需要，调参复杂 | TORQUE_MIN / TORQUE_MAX 油门线性 |
| 连续油门（throttleLevel 0.0~1.0 渐变） | 油门始终 100%，不需要渐变 | 恒为 1.0 |
| 质量自适应扭矩（mass × g × 0.02） | 扭矩与质量解耦，由轮胎摩擦圆限制 | 固定 TORQUE_MAX |
| 扭矩平衡负载模型（loadFactor） | RPM 不再积分演化 | 油门直控 RPM |
| 发动机-轮速耦合 | RPM 不再受轮速约束 | 油门直控 RPM |
| 换挡 RPM 同步 | RPM 恒为 6,000 无同步必要 | — |
| 指令转速分离 | 不再需要 | — |
