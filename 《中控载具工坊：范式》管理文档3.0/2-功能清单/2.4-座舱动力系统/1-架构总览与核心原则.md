# 1. 架构总览与核心原则

> ⚠ 06-27 更新：发动机简化，移除连续油门/质量自适应扭矩/扭矩曲线/负载模型/轮速耦合

## 架构总览

```
玩家输入 (W/S) ──→ SuspensionBE.applyControlInput()
                        │
                        └─ throttleForward/Backward (布尔状态，仅方向)
                                 │
                                 ▼
                      CockpitBE.tick()
                        │  throttleLevel = 1.0 (恒为 100%)
                        │  EngineModel.computeThrottleControlledRun(1.0)
                        │    → RPM = 6000, Torque = TORQUE_MAX (5.0 Nm)
                        │
                   变速箱 (gearRatio × FINAL_DRIVE_RATIO)
                        │
                   差速分配 (/ N wheels)
                        │
                    SuspensionBE.physicsTick() 读取 torquePerWheel
                     + BinaryGrip 方向闸门 (WASD)
                     + 摩擦圆约束 (最终限幅器)
```

### 核心原则
1. **油门始终 100%**：`throttleLevel` 恒为 1.0，引擎永远满扭矩，WASD 仅控制 BinaryGrip 方向
2. **扭矩与 RPM 解耦**：`Torque = TORQUE_MIN + throttle × (TORQUE_MAX - TORQUE_MIN)`，无 RPM 依赖
3. **变速箱纯数学变换**：扭矩 × 齿比 → 轮端，不影响发动机状态
4. **轮胎是唯一限幅器**：摩擦圆决定实际地面驱动力
5. **空档自动挂档**：W/S 按下时从 N 瞬跳 1 档
6. **主减速比**：`FINAL_DRIVE_RATIO=14.0`，所有档位最终传动比 = 齿比 × 主减速比
