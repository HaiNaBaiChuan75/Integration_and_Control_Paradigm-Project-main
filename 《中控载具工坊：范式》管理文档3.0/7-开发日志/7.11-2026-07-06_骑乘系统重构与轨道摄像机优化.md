# 7.11 — 2026-07-06 骑乘系统重构与轨道摄像机优化

## 概述

一次全面的骑乘系统翻新：移除旧 mount 系统（F 键上车、玩家隐藏、伤害免疫、服务端位置同步），`BaseCabinBlock` 使用 `IACPSeatEntity` 复刻 Create Seat + Sable 物理跟随，轨道摄像机改为基于原版 F5 第三人称。

## 核心变更

### 1. IACPSeatEntity — 完整座位实现

新增 `entity/IACPSeatEntity.java`，完整复刻 Create `SeatEntity`：
- 极小碰撞箱 (0.25×0.35)、noPhysics、不可渲染、不可推动
- `positionRider()` → 玩家坐在方块表面上方 1/16 格
- `tick()` → `Sable.HELPER.getContaining()` → `logicalPose().transformPosition(homePos)` 跟随 SubLevel
- `followSubLevelPose()` → 从 pose 法线计算 yaw，双端执行
- 占座检测、换人、生命周期（方块消失 → discard）

### 2. 抖动修复

去除 `tick()` 中的 `isClientSide` 守卫，客户端直接读取本地 SubLevel `logicalPose()` 更新座位位置，不再依赖服务端 20Hz 位置同步包。vanilla 实体插值自动平滑帧间过渡。

### 3. 旋转跟随

- `followSubLevelPose()` 计算帧间 `yawDelta`，存储为 `lastYawDelta`
- 服务端：应用到所有骑乘者 `passenger.setYRot(yRot + delta)`（权威同步）
- 客户端：`ClientMountGameHandler.onClientTickPost` 读取 delta 修正本地玩家
- 首次 tick 跳过（`firstTick` 标记），防止骑乘瞬间快照旋转

### 4. 轨道摄像机重构

`CameraMixin.java`：
- 由始终覆盖改为仅 `thirdPerson == true` 时激活
- 移除独立 `orbitalYaw/orbitalPitch` 状态 + 低通滤波器
- 复用原版 Camera 的 `yRot/xRot`（来自玩家鼠标）
- 处理 `inverseView`（第三人称正面翻转）
- `ClientMountHandler.java`：删除 ~140 行轨道状态代码

### 5. 旧 mount 系统精简

- 移除 F 键上车、射线检测、CockpitUpperBlock 结构检查
- 移除 `MountedProtectionHandler`（伤害免疫）
- 移除服务端玩家位置同步、隐藏、invisible 设置
- 移除 `SablePostPhysicsTickEvent` 中的玩家状态设置
- `ClientEvents`：移除 MOUNT_KEY 按键、`onRenderPlayer` 事件
- `SeatMountC2SPacket` → 删除（右键交互走 `useWithoutItem`）

## 后续工作（2026-07-06 第二波）

### 6. IACPSeatEntity → Create Seat 差异修复（5项）

| # | 问题 | 修复 |
|---|------|------|
| ① | tick 时序：`super.tick()` 的 `positionRider` 用旧 `riderWorldPos` | 前移 `followSubLevelPose`，后置 `positionRider` 重调 |
| ② | 缺 `yBodyRot` 跟随 | 服务端+客户端均加 `yBodyRot += yawDelta` |
| ③ | 缺 `setPos` 碰撞箱居中覆写 | 添加 Create 相同的 setPos → AABB 居中 |
| ④ | `updateInterval=3` 默认 | 改为 `Integer.MAX_VALUE` |
| ⑤ | `trackingRange=10` 过高 | 改为 5 |

### 7. 载具控制集成（首个骑乘者）

IACPSeatEntity 服务端 tick 注册首个骑乘者到 `PlayerMountTracker`：
- `tryRegisterMountControl()` → `PlayerMountTracker.mount()` + `MountedStateS2CPacket`
- 客户端 `ClientMountHandler.isMounted=true` → WASD 映射、悬挂扫描、信息覆盖层恢复
- `isSubLevelOccupiedByOther()` 防止同 SubLevel 多玩家控制
- 下车/断线/死亡 → `unregisterMountControl()` + `remove()` 兜底

### 8. 载具参照摄像机模式（VehicleCameraMixin）

新增两种以 SubLevel 为参考系的摄像机模式，**独立于 F5 循环**，F6 键切换：

| 模式 | 转换方式 | 效果 |
|------|----------|------|
| 结构固定 | `Pose3d.transformPosition(localOffset)` 全量变换 | 画面随车体晃动 |
| 方向稳定 | 仅 yaw 旋转 + 位移，移除俯仰/侧倾 | 地平线保持水平 |

实现：`mixin/VehicleCameraMixin.java` + `client/VehicleCameraMode.java`

### 9. CameraMixin 跳过 IACPSeatEntity

`resolveClientSubLevel()` 检测骑乘 IACPSeatEntity → 返回 null（不再覆盖相机位置/旋转），F5 原版管线围绕骑乘者实体做轨道。
