## Physics Assembler（物理装配器）

### 设计目标

玩家按住 Ctrl + 鼠标右键，从玩家眼睛发射 3 格射线：
- 命中主世界中的驾驶舱（CockpitBlock / BaseCabinBlock）→ **装配**：BFS 扫描相连方块 → 创建 SubLevel
- 命中已装配的 SubLevel → **拆解**：PD 伺服对齐 → 安全检查 → 放回主世界

### 实现演变

**v1（06-28）**：客户端射线检测 → 发送 BlockPos 到服务端 → BFS 装配或拆解。
- 拆解逻辑直接参照 Simulated Physics Assembler 的 PD 伺服对齐方案
- 问题：拆解无效——客户端 `mc.level.clip()` 在 SubLevel 装配后返回 MISS

**v2（06-29）**：改为空信号包（`PhysicsAssembleC2SPacket`），服务端从玩家眼睛重发 3 格射线。
- 使用 `SableBlockHelper.rayTraceSubLevels()` 实现 SubLevel 感知射线检测
- 装配：`SubLevelAssemblyHelper.assembleBlocks()` + BFS flood fill（半径 16，上限 30000 方块）
- 拆解：FreeConstraint PD 伺服对齐（LINEAR_STIFFNESS=1000, ANGULAR_STIFFNESS=13000）→ 对齐误差 <1° 且 <0.2m 持续 5 tick → `moveBlocks()` + `removeSubLevel()`

**v3（06-29 晚）**：解决拆解后立即重装配的"闪烁"问题。
- 根因：拆解将方块放回主世界后，服务端射线立即再次检测到驾驶舱 → 再次装配
- 修复：添加 `PLAYER_COOLDOWNS`（Map<UUID, Integer>），每次操作后设置 20 tick 冷却
- `onServerTick` 中递减冷却，冷却期内 `handleAssembleSignal` 直接 return

### 关键文件

| 文件 | 职责 |
|------|------|
| `events/PhysicsAssembleHandler.java` | 核心处理器：handleAssembleSignal（服务端射线）、assembleFromCockpit（BFS+SubLevel）、tryDisassemble（安全检查+PD伺服）、tickDisassembling（每 tick 对齐）、placeIntoWorld（放回世界） |
| `network/packets/PhysicsAssembleC2SPacket.java` | 空信号包（StreamCodec.unit），C→S 触发装配/拆解 |

### PD 伺服参数

| 参数 | 值 | 说明 |
|------|-----|------|
| LINEAR_STIFFNESS | 1000.0 | 线性弹簧刚度 |
| LINEAR_DAMPING | 50.0 | 线性阻尼 |
| ANGULAR_STIFFNESS | 13000.0 | 角度弹簧刚度 |
| ANGULAR_DAMPING | 1000.0 | 角度阻尼 |
| DISASSEMBLY_DEGREE_TOLERANCE | 1.0° | 角度对齐容忍度 |
| DISASSEMBLY_DISTANCE_TOLERANCE | 0.2m | 位置对齐容忍度 |
| MAX_DISASSEMBLY_TICKS | 100 | 超时保护 |
| PLAYER_COOLDOWN_TICKS | 20 | 玩家操作冷却 |

### 安全检查

拆解前执行三项安全检查：
1. **世界高度**：SubLevel 边界必须在世界构建范围内
2. **速度检查**：线速度 ≤ 5.0 m/s，角速度 ≤ 2.0 rad/s
3. **半空检查**：SubLevel 下方 1 chunk 范围内必须有非空气方块

### 已知限制

- 装配后 SubLevel 无归属系统注册（未接入 AffiliationRegistry）
- 无装配/拆解成功的玩家反馈消息
- 多人游戏未测试
